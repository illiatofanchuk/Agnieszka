# Локальний прототип

Запуск із папки проєкту:

```sh
python3 -m http.server 4187 --bind 127.0.0.1 --directory prototype
```

[Поточний перегляд](http://127.0.0.1:4187/) використовує збережений вибір версії, а при першому відкритті — V1. Прямі посилання для порівняння:

- [V1 — Відкритий простір, PL](http://127.0.0.1:4187/?v=1&lang=pl) · [UK](http://127.0.0.1:4187/?v=1&lang=uk).
- [V2 — Bliskość, PL](http://127.0.0.1:4187/?v=2&lang=pl) · [UK](http://127.0.0.1:4187/?v=2&lang=uk).
- [Warsztaty](http://127.0.0.1:4187/warsztaty/) і [Sklep](http://127.0.0.1:4187/sklep/) — окремі сторінки зі збереженим дизайном V1. Їхній перемикач V1 / V2 веде до відповідної головної.

Порт 4173 належить іншому сайту; для цього прототипу використовується 4187. V2 додає альтернативні hero та нижні блоки за референсом [Bliskość](../.impeccable/reference/v2-bliskosc.png), V1 доступна поряд. Плаваючий перемикач V1 / V2 оновлює `?v=1|2` і зберігає вибір у `localStorage` під ключем `agnieszka-version`. PL / UK перемикає весь інтерфейс, оновлює `?lang=pl|uk` і зберігає вибір під ключем `agnieszka-language`. Явні параметри адреси мають пріоритет над збереженим вибором. PL — основна мова; UK призначена для перегляду й погодження.

Форма спільна для обох версій: дія конкретної послуги попередньо вибирає її. Форма демонстраційна: перевіряє поля й показує приклад підтвердження, без надсилання заявки до сервера та без email. Ім’я, email та інші введені поля залишаються тільки в пам’яті відкритої сторінки; вибір мови й версії зберігається окремо в браузері. Чернетка й послуга зберігаються під час зміни мови у формі. Події та продукти позначені як приклади. Покупки відсутні. Статті й правові документи мають пояснення про підготовку матеріалів.

## Зображення та запити генерації

Композиція першого екрана V1 заснована на погодженому макеті 1. Його фотографічне тло згенероване на основі макета; оригінальні фотографії інших секцій витягнуті з наданого `Home 4.pdf`. Точний запит V1 збережено в [hero-open-sky.prompt.txt](assets/hero-open-sky.prompt.txt).

Зображення V2 створено через вбудовану генерацію зображень на основі наданого референсу й фотографій. Це візуалізація для локального погодження, не документальна нова фотосесія. Кожен оригінальний PNG містить точний запит у метаданих; окремі копії запитів лежать поруч:

| Матеріал V2 | Роль | Точний запит |
|---|---|---|
| [hero-meadow.png](assets/v2/hero-meadow.png) | Повне hero-тло | [hero-meadow.png.prompt.txt](assets/v2/hero-meadow.png.prompt.txt) |
| [hero-subject.png](assets/v2/hero-subject.png) | Прозорий шар людини поверх HTML-заголовка | [hero-subject.png.prompt.txt](assets/v2/hero-subject.png.prompt.txt) |
| [about-hands.webp](assets/v2/about-hands.webp) / [оригінал PNG](assets/v2/hands-detail-hq.png) | Чіткий окремий кадр рук у About, 1157×1359, без CSS-збільшення hero | [точний запит](assets/v2/about-hands.webp.prompt.txt) |
| [portrait.png](assets/v2/portrait.png) | Портрет у About | [portrait.png.prompt.txt](assets/v2/portrait.png.prompt.txt) |

V2 використовує Manrope 400 у великих заголовках. V1 — Mulish для заголовків і Manrope для інтерфейсу. Відкриті шрифти збережено локально; [Manrope OFL](assets/OFL-Manrope.txt) і [Mulish OFL](assets/OFL-Mulish.txt) додані до assets.

## Межі та перевірка

[Дизайн-система й локальні перевизначення V2](../DESIGN.md), [контракт V2](../design/home-v2.md), [перевірка V1](VERIFICATION.md), [перевірка V2](../.impeccable/review/v2/VERIFICATION.md) і [11 успішних перевірок взаємодії V2](../.impeccable/review/v2/interaction-checks.json) описують поточний стан. [Незалежний огляд V2](../.impeccable/review/v2/REVIEW.md) має висновок `ship` для перевіреної локальної композиції та взаємодій; у ньому окремо збережено рекомендацію щодо часткового перекриття hero-дії перемикачем на 325px. Збережені числові порівняння V1 стосуються лише V1; числової оцінки схожості V2 немає.

Перед публічним запуском потрібні погоджені тексти й кваліфікація, актуальні події та умови послуг, контакти, правові документи й налаштоване надсилання на email. Публікація, оплати, зовнішні інтеграції та повний аудит доступності не виконувалися. Прототип призначений для локального погодження.
