# Іконки — handmade fill

Єдиний набір із чотирьох оливкових ілюстрацій для сайту Agnieszka:

- `sessions-1to1.png` — двоє співрозмовниць у кріслах, турбота й увага.
- `yoga.png` — постать у позі дерева.
- `meditation.png` — сидяча постать зі спокійним виразом обличчя.
- `workshops.png` — невелика група за спільним столом із відкритою книгою.

Залиті органічні форми, м’які нерівні краї, стримана фактура ручного друку. Оливковий орієнтир — `#303829`; найкраще читатимуться на світлому кремовому тлі сайту.

Кожне зображення — PNG RGBA, 1254×1254, із прозорим тлом. Це растрові ілюстрації. Для використання в інтерфейсі варто показувати їх у однакових рамках з `object-fit: contain`.

Створено вбудованою генерацією зображень. Перша ілюстрація стала стильовим референсом для інших трьох. Точний запит кожного файлу збережений поряд у `*.prompt.txt` та в метаданих PNG. `manifest.json` містить перевірені розміри й наявність прозорості.

## Векторні версії

У папці [svg](svg/README.md) додано чотири редаговані SVG через Vectorize. Вони мають прозоре тло та справжні векторні контури. [Архів SVG](agnieszka-handmade-icons-svg.zip) містить весь векторний набір.
