# Векторні іконки

Чотири редаговані SVG, векторизовані з PNG набору handmade через Vectorize:

- `sessions-1to1.svg` — Сесії 1:1.
- `yoga.svg` — Йога.
- `meditation.svg` — Медитація.
- `workshops.svg` — Воркшопи.

Прозоре тло, залиті оливкові форми, спільна квадратна рамка `1258×1258`. Іконки містять векторні контури, без вбудованих растрових зображень. Масштабуються й редагуються у Figma, Illustrator та інших SVG-редакторах. Результати й налаштування сервісу збережені у `vectorize-manifest.json`.
